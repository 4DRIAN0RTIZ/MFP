01 / What it does

Everything in the terminal

01

Progressive Streaming

Starts playing after a 512 KB buffer — no waiting for the full episode to download.

02

Live Visualizer

Six animated styles that move with the music. Switch with v, turn off with V. See the styles.

03

Full Playback Controls

A full-screen player with an episode list and search; play/pause, volume, mute, next, previous, shuffle — all from the keyboard while it runs.

04

Color Themes

Six built-in themes, or make your own with a small text file. Choose your colors.

05

MPRIS Integration

Exposes D-Bus MPRIS so Polybar, KDE, GNOME, and any media client can see and control it.

06

Save episodes to disk

Save episodes to ~/.config/mfp/downloads/ with d or mfp download. mfp still streams episodes when you play them.

07

Favorites

Mark episodes as favorites and play only those, with or without shuffle.

08

Zero External Deps

Pure Rust audio pipeline — no mpv, no ffmpeg. MP3, FLAC, AAC, ALAC, Vorbis, WAV.

02 / Installation

Get it running

1

Step 1: Clone & build

Requires Rust stable. The release profile strips debug info and optimizes for size (the binary is about 5 MB).

git clone https://github.com/4DRIAN0RTIZ/mfp && cd mfp cargo build --release
2

Step 2: Add to PATH (optional)

Copy the binary system-wide so you can run mfp from anywhere.

sudo cp target/release/mfp /usr/local/bin/
3

Step 3: Play

Running mfp opens the full-screen player. It is the same as mfp play. Press q to quit. See Using the player for all the keys.

03 / Commands

Quick reference

▶ Play
mfp  # start the player
mfp play  # same thing
mfp play -e 75  # start at episode 75
mfp play --episode 75  # long form of -e
mfp play -s  # shuffle
mfp play --shuffle  # long form of -s
mfp play -f  # favorites only
mfp play --favorites  # long form of -f
mfp play -f -s  # favorites + shuffle
mfp play --compact  # start with the list hidden
mfp play --plain  # text mode, type a command + Enter
★ Favorites
mfp fav -l  # list
mfp fav --list  # long form of -l
mfp fav -a "Episode 75"  # add
mfp fav --add "Episode 75"  # long form of -a
mfp fav -r "Episode 75"  # remove
mfp fav --remove "Episode 75"  # long form of -r
⬇ Downloads
mfp download -e 75  # download an episode
mfp download --episode 75  # long form of -e
mfp download -l  # list what you downloaded
mfp download --list  # long form of -l
mfp download -s  # disk usage
mfp download --size  # long form of -s
mfp download -d "Episode 75"  # delete a download
mfp download --delete "Episode 75"  # long form of -d
≡ List, help and version
mfp list  # all episodes
mfp --help  # all options (short: -h)
mfp play --help  # options of one command
mfp --version  # show the version (short: -V)

Options of mfp and mfp play

Running mfp with no command is the same as mfp play and accepts the same options.

Options of mfp play
OptionWhat it does
-e, --episode <N>Start at this episode number (for example 75). It starts at the first episode titled “Episode N…”; a plain text match, so 1 also matches “Episode 12”. If nothing matches, it starts at the beginning.
-s, --shuffleShuffle the playlist. Toggle it at any time with s.
-f, --favoritesPlay only your favorites (see mfp fav).
--plainUse the plain text mode instead of the full-screen player. More about text mode.
--compactStart with the episode list hidden (player only). It cannot be combined with --plain.
-h, --helpShow help.
-V, --versionShow the version.

04 / Using the player

What you see and what to press

The screen

When you run mfp it fills your terminal window. On a normal-sized window you get two panels side by side:

  • Episodes (left). The full list of episodes. A ▶ marks the one that is playing and a ★ marks your favorites.
  • Player (right). The episode title, a progress bar with the time played and the total time, the volume, whether shuffle is on, and a dot that is filled when your desktop media keys are connected. Below that you see the visualizer and a line for short messages, such as "downloading" or an error.
  • Help line (bottom). A reminder of the most useful keys.

Two views

Press h to hide the episode list and give the whole window to the player and visualizer. Press h again to bring the list back. You can also start with the list hidden using mfp play --compact.

You do not have to choose: until you press h, mfp picks the view from the size of your window. Below about 80 columns by 16 rows it uses the compact view by itself and switches back when you make the window bigger. Once you press h, your choice sticks for the rest of the session. Showing the list needs at least 64 by 12; on a smaller window h does nothing. If the window is really tiny (under 40 by 9) mfp asks you to make it bigger. When the list is hidden, the keys that move around the list do nothing.

Keys

Just press the key, no Enter needed. Keys are case-sensitive: v and V do different things.

Searching

Press / and start typing: the list narrows down as you type. While you are typing, letters go into the search box, so they will not trigger the keys above. Press Enter to keep the filtered list, or Esc to clear the search. The arrows, Page Up/Page Down, Home and End still move the selection while you search, and Ctrl+C always quits.

The list keys (moving, Enter, /) only work while the episode list is shown.

05 / Visualizer

Watch the music move

While an episode plays, mfp draws the sound as a live animation under the player. It reacts to what you are hearing: bass on the left, treble on the right. When you pause, it settles down to nothing. It only listens; it never changes the audio.

Press v to switch to the next style, and V to turn the animation off or on. If it is off, v turns it on again with the next style. In the compact view the visualizer is shown when the window is at least 13 rows tall.

Choose the starting style

The style you pick with v and V lasts until you quit. To choose what mfp starts with, add a [visualizer] section to your config file:

[visualizer] style = "wave" # bars, mirror, wave, dots, area or vu enabled = true # false starts with the visualizer off

If the style name is not recognized, mfp starts with bars and writes a note to its log file.

Choose a theme

Create the file ~/.config/mfp/config.toml (create the folder if it does not exist yet) with the name of the theme:

# ~/.config/mfp/config.toml [theme] active = "nord" [visualizer] style = "bars" enabled = true

Every line is optional. Leave out anything you do not want to change. Restart mfp to see the change.

Make your own theme

A theme is a small text file in ~/.config/mfp/themes/. Name it after your theme: a file called midnight.toml is chosen with active = "midnight". Your file starts from one of the built-in themes (using base) and changes only the colors you list. If you leave out base, it starts from default. The base has to be one of the six built-in themes, not another theme of your own.

# ~/.config/mfp/themes/midnight.toml base = "nord" accent = "#c5a85b" viz_high = "light-red" favorite = "yellow"

Then select it in config.toml:

[theme] active = "midnight"

How to write a color

  • A name: "cyan", "red", "light-blue", "dark-gray", "white". The names are black, red, green, yellow, blue, magenta, cyan, gray, dark-gray and white, plus a light- version of the bright ones. These use your terminal's own palette, so the exact shade depends on your terminal.
  • A hex code: "#c5a85b". Exactly six digits after the #. This needs a terminal that shows millions of colors; most modern ones do.
  • A number from 0 to 255: "166", from the standard 256-color palette.
  • "reset": use your terminal's own color.

Always put the color in quotes.

Every color you can change

Each line in your theme file is one of these names, set to a color.

If something is wrong

mfp never refuses to start because of a theme. If the theme file is missing, has a typo in an option name, uses a color it does not understand, or names a base that is not built in, mfp shows the default look and writes the reason to its log file. The same goes for a config file it cannot read: it uses the defaults and logs why. Look at the log if your theme does not appear.

Tip: if you copy the example above and nothing changes, check the spelling of the option names. An unknown name makes the whole theme file fail, not just that line.

07 / Configuration and files

Where things live

Everything mfp saves is kept in one folder, ~/.config/mfp/. If you have set $XDG_CONFIG_HOME, mfp uses $XDG_CONFIG_HOME/mfp/ instead.

Files and folders used by mfp
PathWhat it is
config.tomlYour settings: the theme and the starting visualizer style. Optional; you create it.
themes/Your own themes, one .toml file each. Optional.
favorites.jsonYour favorite episodes.
downloads/Episodes you saved with d or mfp download.
mfp.logA short log. mfp writes here when something goes wrong quietly, for example the media-keys connection is not available or a theme could not be loaded.

mfp only reads config.toml and your theme files. It never edits or creates them, so your own comments and formatting are safe. Changes you make with v and V last until you quit; to keep them, edit the file yourself.

Settings are read once, when mfp starts. Restart it after editing the files.

08 / Text mode

Plain text mode and pipes

Prefer the original, simple interface? Run mfp play --plain. Instead of a full-screen window, mfp prints status lines and waits for you to type a command and press Enter.

mfp play --plain
Commands of text mode
TypeWhat it does
n or nextNext episode
b, back, prev or previousPrevious episode
p, pause or playPause / resume
+ or upVolume up
- or downVolume down
m or muteMute / unmute
s or shuffleShuffle on / off
f, fav or favoriteAdd / remove favorite
i or infoEpisode info
d or downloadDownload this episode
q, quit or exitQuit

Text mode has no visualizer and no themes. The options -e, -s and -f work here too, but --compact does not (it belongs to the full-screen player).

Automatic fallback

mfp switches to text mode by itself when it cannot draw a full-screen window: when its input or output is redirected or piped (for example mfp play | cat, or when a script runs it), or when your terminal says it is “dumb” (TERM=dumb, used by some minimal environments). Typing just mfp in that situation only prints a short overview of the commands, so music never starts by surprise.

You can also feed it commands from another program. When the input is redirected, each line is read as a command, and the moving progress line is not drawn. If that input ends, the music keeps playing (closing the input is not a request to quit). Send q before it ends to quit, or stop it with Ctrl+C or your media keys.

printf 'i\nq\n' | mfp play

09 / Your library

Favorites, downloads and the episode list

Favorites

Press f in the player to mark the current episode with a star, or manage them from the command line. To listen to only your favorites, start with mfp play -f.

mfp fav -l # show your favorites (--list) mfp fav -a "Episode 75" # add one (--add) mfp fav -r "Episode 75" # remove one (--remove)

Downloads

Press d in the player, or use the command line, to save an episode in the downloads folder (see Files). mfp still streams episodes when you play them.

mfp download -e 75 # download episode 75 (--episode) mfp download -l # list what you have downloaded (--list) mfp download -s # how much disk space it uses (--size) mfp download -d "Episode 75" # delete a download (--delete)

The episode list

mfp list prints every episode in the terminal, which is handy for finding a number to use with -e.

mfp list

10 / Media keys and integrations

Media keys, MPRIS & Polybar

mfp plays nicely with the rest of your desktop. While it runs, your keyboard's media keys (play/pause, next, previous), the media widget of your desktop, and panel widgets such as Polybar or Waybar can see and control it. You can also control it from a script with playerctl. If your system does not support this, mfp keeps playing and just leaves the connection off (the dot in the player stays empty).

playerctl -p org.mpris.MediaPlayer2.mfp play-pause

MFP exposes a D-Bus MPRIS interface as org.mpris.MediaPlayer2.mfp. Any MPRIS-compatible client can control it — Polybar, Waybar, KDE, GNOME Shell, playerctl, AGS, eww, and more.
