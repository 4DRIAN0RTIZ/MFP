mfp — Music For
Programming Player

Lightweight terminal player for musicforprogramming.net. Streams directly, no external dependencies, MPRIS support.

Get started GitHub
mfp play
What it does

Everything in the terminal

⚡

Progressive Streaming

Starts playing after a 512 KB buffer — no waiting for the full episode to download.

🎛

Full Playback Controls

Play/pause, volume, mute, next, previous, shuffle — all from the keyboard while it runs.

📡

MPRIS Integration

Exposes D-Bus MPRIS so Polybar, KDE, GNOME, and any media client can see and control it.

💾

Offline Downloads

Download episodes to ~/.config/mfp/downloads/ and listen without a connection.

⭐

Favorites

Mark episodes as favorites and play only those, with or without shuffle.

📦

Zero External Deps

Pure Rust audio pipeline — no mpv, no ffmpeg. MP3, FLAC, AAC, ALAC, Vorbis, WAV.

Installation

Get it running

1

Clone & build

Requires Rust stable. The release profile strips debug info and optimizes for size (~3.6 MB).

git clone https://github.com/4DRIAN0RTIZ/mfp && cd mfp cargo build --release
2

Add to PATH (optional)

Copy the binary system-wide so you can run mfp from anywhere.

sudo cp target/release/mfp /usr/local/bin/
3

Play

mfp play
Commands

Quick reference

▶ Play
mfp play                  # first episode
mfp play -e 75           # specific episode
mfp play -s              # shuffle
mfp play -f              # favorites only
mfp play -f -s           # favorites + shuffle
★ Favorites
mfp fav -l              # list
mfp fav -a "Episode 75" # add
mfp fav -r "Episode 75" # remove
⬇ Downloads
mfp download -e 75       # download ep
mfp download --list      # list cached
mfp download --size      # disk usage
mfp download --delete … # remove ep
≡ List
mfp list                  # all episodes

Integrations

MPRIS & Polybar

MFP exposes a D-Bus MPRIS interface as org.mpris.MediaPlayer2.mfp. Any MPRIS-compatible client can control it — Polybar, Waybar, KDE, GNOME Shell, playerctl, AGS, eww, and more.

Any MPRIS client

🎵

KDE / Plasma

Media widget picks it up automatically.

🐚

GNOME Shell

System media controls in the top bar.

📊

Waybar

Use the built-in mpris module.

⌨️

playerctl

Full CLI control from any script.

playerctl — quick reference
# target mfp specifically
playerctl --player=org.mpris.MediaPlayer2.mfp play-pause
playerctl --player=org.mpris.MediaPlayer2.mfp next
playerctl --player=org.mpris.MediaPlayer2.mfp previous
playerctl --player=org.mpris.MediaPlayer2.mfp volume 0.1+
playerctl --player=org.mpris.MediaPlayer2.mfp metadata xesam:title

Polybar module

Always-visible module — shows current episode while playing, stays in the bar when idle. Controls via mouse clicks, no extra daemon needed.

playerctl rofi (optional — context menu)
1

Copy scripts

Two scripts handle status polling and click actions.

mkdir -p ~/.config/polybar/scripts curl -sLo ~/.config/polybar/scripts/mfp-status-v2.sh \ https://raw.githubusercontent.com/4DRIAN0RTIZ/mfp/main/contrib/polybar/scripts/mfp-status-v2.sh curl -sLo ~/.config/polybar/scripts/mfp-action.sh \ https://raw.githubusercontent.com/4DRIAN0RTIZ/mfp/main/contrib/polybar/scripts/mfp-action.sh chmod +x ~/.config/polybar/scripts/mfp-*.sh
2

Add module to polybar config

Paste this block into your config.ini, then add mpris to modules-left / modules-right.

config.ini
[module/mpris]
type         = custom/script
exec         = ~/.config/polybar/scripts/mfp-status-v2.sh
interval     = 2
format       = <label>
label        = %output%
click-left   = ~/.config/polybar/scripts/mfp-action.sh left
click-right  = ~/.config/polybar/scripts/mfp-action.sh right
click-middle = ~/.config/polybar/scripts/mfp-action.sh middle
scroll-up    = ~/.config/polybar/scripts/mfp-action.sh scroll-up
scroll-down  = ~/.config/polybar/scripts/mfp-action.sh scroll-down
